# 帆影 SolarView · 卫星帆板受照与发电推演

一个纯浏览器运行的微小卫星太阳翼受照、阴影、旁路二极管与整轨功率推演原型。界面使用 TypeScript，三维渲染和逐电池片阴影计算使用手写 WebGPU/WGSL；方案、当前工作区和对比工况保存在浏览器 IndexedDB。

## 运行

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址（默认 <http://127.0.0.1:5173>）。建议使用最新版 Chrome / Edge 并确认 `chrome://gpu` 中 WebGPU/Hardware acceleration 可用。无 WebGPU 设备时会自动切换 CPU 兼容计算引擎，三维 WebGPU 视图不可用，但参数、表格、曲线和导出仍可使用。

生产构建：

```bash
npm run build
npm run preview
```

自动化测试：

```bash
npm test
```

## 页面

1. **卫星构型**
   - 长方体、平板、圆柱三类基本体，可建星体、天线、支架和相机遮光罩。
   - 太阳翼按铰链位置、铰链轴、展开角、驱动机构转角、行列片数、片尺寸/间隙参数化生成。
   - 每片电池片输出本体中心、法向、两个边方向、串号和旁路二极管组号。
   - 可导出 `cell_positions.csv`。
   - 内置两套测试构型：500 kg 级（224 片）和 50 kg 级（80 片）。

2. **轨道与姿态**
   - 录入半长轴、偏心率、倾角、RAAN、近地点幅角、初始平近点角和历元。
   - 可按 J2 太阳同步回归条件一键计算 SSO 倾角。
   - 日期驱动低精度太阳 ECI 矢量和地影进出时刻。
   - 姿态支持对地定向、对日定向和惯性定向。
   - 偏航/俯仰/滚动机动使用四元数 SLERP 做进入/退出插值，可插入多段机动。

3. **受照推演**
   - WebGPU 计算着色器按“历元 × 电池片 × 片内分层采样点”进行自定义光线求交。
   - 支持长方体/平板 AABB 和有限圆柱求交，计算星体、天线、遮光罩、太阳翼基板之间的自遮挡。
   - 地球反照采用经验反照率 × 地球视圆盘角系数 × 日照因子。
   - 多次反射/反照使用确定性余弦半球采样和可配置弹射次数。
   - 三维视图按当前历元四元数显示构型，电池片按综合受照率、阴影采样率或直接太阳辐照上色。
   - 时间轴可拖动和播放，右侧显示每串电流、电压、功率和被旁路的二极管组数量。

4. **发电曲线**
   - 输出一整轨功率曲线、直接太阳功率虚线、地影带、载荷阈值线。
   - 标注全轨最小功率点和光照区几何最差功率点。
   - 列出地影进入/退出时刻、持续时间和最低功率历元。
   - 导出功率曲线 CSV、完整电池片受照时间表 CSV 和 Markdown 工况说明。

5. **工况对比**
   - 将多套“构型 + 姿态”保存到 IndexedDB。
   - 对比时强制使用当前页的同一天日期和同一套轨道六根数。
   - 功率曲线叠加，差值表给出峰值、全轨最小、光照区最差和发电量差值，可选择基线并导出 CSV。

6. **设置与验收**
   - 配置步长、阴影采样密度、太阳常数、地球反照系数、多次反照光线数/弹射次数、载荷阈值和 WebGPU 开关。
   - 显示 WebGPU 适配器状态。
   - 内置余弦定律自检和 10 s 步长整轨性能验收。
   - 支持方案 JSON 导入/导出和 IndexedDB 清理。

## 电学模型说明

串联电池片不能简单按受光面积线性折算。系统先根据每片总辐照得到其光生电流上限，再按串的物理接法分组：

- 未启用旁路二极管时，整串电流受最弱电池片限制。
- 启用旁路二极管时，以各旁路组最弱电流作为候选串电流；电流超过某组上限后，该组被旁路并损失该组电压，而不是把整片阵列按面积比例相乘。
- 默认每串独立 MPPT，阵列功率为各串最大输出功率之和。

无遮挡且所有电池片入射角相同时，模型为 `P(θ)=P₀ cos θ`。自动化测试和设置页自检覆盖 0°–82°，最大误差为 `0.0000%`，验收阈值 `<0.5%`。

## 性能口径

默认 500 kg 级构型为 224 片电池片、581 个 10 s 历元（约 96.7 min 轨道周期）。阴影主计算在 WebGPU 中一次批量提交并回读；电学汇总和曲线在主线程完成。无 WebGPU 适配器的测试环境中，CPU 兼容路径实测约 2.0–2.8 s（含多次反照），目标 WebGPU 浏览器通常更快。设置页“按 10 s 步长运行性能验收”会显示当前机器的实际页面耗时。

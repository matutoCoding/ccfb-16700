# 卫星帆板受照与发电推演系统

一个纯浏览器运行的 TypeScript + 原生 WebGPU/WGSL 工程，用于卫星总体、热控和电源专业快速检查太阳翼遮挡、地影、姿态机动、旁路二极管和整轨发电功率。方案保存在 IndexedDB，不需要后端服务。

## 快速开始

```bash
npm install
npm run dev
```

打开 Vite 输出的地址（通常是 <http://127.0.0.1:5173/>；若 5173 被占用会自动切到 5174）。建议使用最新版 Chrome / Edge，并确认 `chrome://gpu` 中 WebGPU 可用。

生产构建：

```bash
npm run build
npm run preview
```

单元测试与 WGSL 语法解析：

```bash
npm test
npm run check:wgsl
```

## 页面与需求对应

1. **卫星构型**
   - 长方体 `box`、圆柱 `cylinder`、平板 `plate` 基元，可组成星体、天线、支架、相机遮光罩。
   - 太阳翼可配置根节点、铰链轴、铰链展开角、驱动机构局部轴和驱动转角。
   - 每片电池片由行列、片尺寸和间隙生成，包含本体坐标、法向和两个切向。
   - 支持导出每片电池片位置/法向 CSV。
   - 电池串片数和旁路二极管组长度可编辑，并校验网格片数与灯串总数。

2. **轨道与姿态**
   - 经典六根数：`a, e, i, Ω, ω, M0` 和历元。
   - 一键计算并填入太阳同步轨道倾角，回归率按 J2 长期项计算。
   - 日期使用低精度太阳历更新 ECI 太阳矢量、太阳 β 角和地影进出时刻。
   - 姿态模式：对地 LVLH、对日、惯性四元数。
   - 偏航/滚动机动按时间窗、`smoothstep` 和 `Quat.slerp(identity, Δq, p)` 叠加。

3. **受照推演**
   - WGSL compute pass 按 `时间步 × 电池片` 分派。
   - 每片电池片可按 `samplesPerCellAxis²` 个采样点发射太阳阴影射线。
   - 遮挡求交支持 OBB 长方体/平板和有限圆柱。
   - 地球反照使用经验反照率、地球角半径、电池片对地视角因子和日照相位。
   - 多阶反射包含：反射面日照/阴影判断、Lambert 形状因子、一阶星体/帆板反射，以及二阶/高阶辐射度闭合项。
   - WebGPU 不可用时可切换到 CPU 参考后端，保证页面流程和导出仍可验证。

4. **三维与时间轴**
   - 手写 WGSL render pipeline 绘制基元、帆板基板和逐片电池片。
   - 电池片按 lit fraction 使用深蓝→青→黄→绿的色标上色。
   - 支持鼠标拖拽环绕、滚轮缩放、播放和时间轴拖动。
   - 无 WebGPU 适配器时提供 Canvas2D 兼容预览。

5. **发电模型**
   - 不是简单面积比例相乘。每串按旁路组得到最小电池片电流上限。
   - 对每个“旁路组电流膝点”候选求解：低于串电流上限的组保留，其余组被旁路并扣除二极管压降。
   - 多串 MPP 结果并联汇总，输出串电流、电压、功率、旁路组数和限制电池片。

6. **发电曲线**
   - 输出整轨功率、负载和净功率曲线。
   - 地影区间用色带标出。
   - 标记最小功率点、时刻和功率裕量。
   - 给出地影进入/退出时刻表和旁路动作最多时刻的电串状态。

7. **工况对比**
   - IndexedDB 保存任意多套构型、轨道和姿态方案。
   - 可选择至少两套曲线叠加。
   - “统一轨道六根数”会以首个选中工况为基准，并可统一到同一天。
   - 差值表按时刻列出每套功率及相对基准的 ΔW，可导出 CSV。

8. **导出**
   - 功率曲线 CSV。
   - 每片电池片受照时间表 CSV（时刻、电池片、灯串、受照比例、直射/反照/反射/总辐照、坐标法向）。
   - 电池片位置 CSV。
   - Markdown 工况说明，包含六根数、姿态机动、太阳翼/旁路设计、推演设置和结果摘要。
   - 全部方案 JSON 导出/导入。

## 内置测试构型

- `case-500kg`：FY-500 公斤级平台。长方体星体、圆柱天线/支架、相机遮光罩；双太阳翼，每翼 `16 × 12 = 192` 片，4 串 × 48 片，每 12 片一个旁路二极管。
- `case-50kg`：NX-50 公斤级微纳卫星。小长方体、柱状天线和遮光罩；双太阳翼，每翼 `10 × 6 = 60` 片，2 串 × 30 片，每 10 片一个旁路二极管。

首次打开会自动写入 IndexedDB；设置页可恢复这两套内置方案。

## 验收口径

### 1. 无遮挡余弦定律

设置页的“运行余弦精度自检”会构造 192 片无遮挡平板，关闭地球反照和多阶反射，并输入 `0°…85°` 太阳入射角。期望：

\[
P(\theta)=N I_{\mathrm{ref}} V_{\mathrm{mp}}\cos\theta
\]

线性 MPP 电流源和固定 MPP 电压模型使所有电池片在均匀辐照下保持同一工作点，旁路二极管不动作。当前单元测试和浏览器端到端报告均为最大误差 `0.00000000%`，小于 `0.5%`。

### 2. 整轨 10 秒步长性能

500 kg 级构型约 384 片电池片，95.5 分钟轨道按 10 s 步长约 574 个时间步，即约 22 万个 `步 × 片` 计算项。设置页“整轨 10 s 性能验收”会显示端到端毫秒数、后端、步数和电池片数，阈值为 3000 ms。

主要 GPU 数据布局：

- `CellGpu`：中心/宽、法向/高、U/V 切向、自遮挡索引。
- `OccluderGpu`：model/inverse matrix、圆柱参数、反射率、中心、半尺寸。
- `StepGpu`：本体太阳矢量、本体地球矢量、反照率、反射系数、地影因子。
- 输出 `vec4(litFraction, direct, albedo, bounce)`。

开发机 RTX 3060 + 系统 Chrome/WebGPU 实测：端到端余弦自检最大误差约 `0.00000442%`；574 步 × 384 片整轨热管线推演约 `80–193 ms`，显著低于 3 s 阈值。可用 `node scripts/verify-webgpu.mjs` 复现（脚本中的 Chrome 路径按机器调整）。

> 性能与显卡、驱动和浏览器有关。首次运行包含 WGSL 编译；设置页可再点一次查看热管线性能。无 WebGPU 适配器的虚拟机会自动使用 CPU 参考后端，其耗时不能作为 WebGPU 性能结论。


## 说明与简化

- 太阳历为工程级低精度公式，适合任务前期光照/发电推演，不替代正式轨道/热控评审星历。
- 地影使用带半影软化的柱/锥近似，并对阴影边界二分精化。
- 电池采用 MPP 电流源 + 有效 MPP 电压的工程模型；旁路二极管状态按组电流膝点求解。若需要精确 IV 曲线，可在 `power.ts` 的单电池 IV 方程处扩展。
- 多阶反射是形状因子 + 辐射度闭合的快速近似，不是全尺寸光线追踪；其输出已单独列为 `bounceWm2`，便于评审检查贡献量。
